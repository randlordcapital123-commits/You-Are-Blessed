# You Are Blessed Merch Store — Offline Edition

This version is fully offline.

- No Supabase
- No Firebase
- No online database
- No cloud storage
- Products, business details and uploaded images are stored in the browser's Local Storage on the current device.

## Important
Local Storage is device/browser-specific. Data will not automatically appear on another device, and clearing browser site data can remove it. Use reasonably sized/compressed images because browser storage is limited.
